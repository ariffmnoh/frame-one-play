# FRAME ONE - playable test build

Play in the browser: https://ariffmnoh.github.io/frame-one-play/

A first-person photography game in development. This repository only holds the built game for testing;
it is replaced on every publish. Build a2c97e8.

Third-party software and data: Babylon.js (Apache 2.0), SunCalc (BSD 2-Clause), star data from XHIP
(Anderson & Francis 2012, VizieR V/137D) via d3-celestial (BSD 3-Clause, (c) 2015 Olaf Frohn).
